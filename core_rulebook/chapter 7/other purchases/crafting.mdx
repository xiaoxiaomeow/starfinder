# 制造装备与魔法物品

:::origin[[英文原文](https://www.aonsrd.com/Rules.aspx?ID=92)]
:::

具备适当技能的角色可以自行制造装备。制造需要时间，而跨星系企业和配有专用制造机器、无人机的工坊享有规模效益，因此自行制造并不能省钱。不过，只要满足制造要求，你就能获得完全符合自己需要的物品。

只要具备所需的技能、材料、工具和时间，PC就能制造本章中的所有物品。相应技能的技能等级必须达到所造物品的物品等级。各类物品使用的技能如下。

| 物品类别 | 所需技能 |
| :---- | :---- |
| 武器、护甲、载具、科技装备 | 工程 |
| 魔法注能、魔法物品 | 神秘 |
| 混合物品 | 工程与神秘，两者均须达到要求 |
| 毒品、药剂、毒素 | 生命科学或物理科学 |
| 食物、饮料 | 生命科学 |
| 计算机 | 计算机或工程；可制造层级等于技能等级一半的计算机 |
| 不属于上述类别的物品，例如大多数服装、帐篷等 | 工程或神秘 |

GM可以允许以合适的专业技能制造范围更窄的物品。例如，拥有专业（武器匠）的角色或许能制造科技、混合与魔法武器，以及武器注能，但不能制造其他物品。

制造物品需要工具，以及工坊或类似场所。大多数星舰都有划出的合适区域。在大城市，也可以按[住宿](./services.mdx#住宿)的价格租用此类空间。住宿面积对应工坊面积，并限制可制造物品的大小，以及能同时制作同一件物品的人数。

制造一件物品的基础时间通常为4小时。如果相应技能的技能等级比物品等级高5或更多，制造时间减至基础时间的一半；高10或更多，则减至四分之一。体型大于中型的物体，每大一个体型类别，制造时间便翻倍。

制造物品时，你必须拥有总价值等于目标物品价格的[通用聚合物基材](./trade%20goods.mdx#通用聚合物基材)。GM可以允许你拆取类似物品的零件，将被拆物品价值的10%抵作所需UPB。即使魔法和混合物品也使用UPB制造：神秘技能用于将材料塑造成符文，以及制造魔法装置所需仪式的专用器具。

自行制造的装备相比量产物品有几项优势。如果你掌握了能够修理自制物品的技能，修理该物品只需正常时间的一半。在确定自制物品的硬度、生命值和豁免时，将其物品等级视为提高2。计算这些数值的规则见第11章的破坏物体。
